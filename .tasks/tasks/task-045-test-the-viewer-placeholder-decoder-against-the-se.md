## Description

Debt left by the live-connection-slice milestone. The browser viewer reimplements the AIGB placeholder wire format in JavaScript (apps/viewer/src/main.js:14-47), mirroring the Rust encoder and decoder in crates/world-server/src/snapshot.rs:17-21, 87-104 and 110-135. The Rust side has a round-trip test (crates/world-server/tests/placeholder_payload_behavior.rs), but the viewer has none: the only viewer gate step asserts that strings appear in the built index.html (apps/viewer/scripts/smoke.mjs, invoked from scripts/product-check.mjs viewer build + smoke step). Changing PLACEHOLDER_VERSION or the 40-byte body layout would break live spectating while the full gate stays green. Acceptance: a viewer-side test decodes bytes produced by the Rust encoder (checked-in fixture regenerated by a gate step, or generated during the run), asserts tick, digest, and body field values, and asserts that wrong magic, wrong version, and a truncated body list return null; the product gate runs that test as part of the viewer step.
