# Out-of-scope decisions

This directory records rejected or deliberately deferred directions whose
reasoning is likely to matter again.

Create one short Markdown file per direction. Include:

- the direction considered;
- why it is out of scope now;
- evidence or accepted decisions supporting that boundary;
- the task or ADR where it was adjudicated; and
- a concrete revisit condition.

Do not use this directory as a graveyard for one-off ideas or ordinary backlog
work. Actionable work belongs on the task board.
